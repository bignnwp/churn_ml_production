# Документация проекта

Это единая точка входа в документацию `churn_ml_production`.

## Основные документы

| Документ | Назначение |
|---|---|
| [Model Card](model_card.md) | Назначение модели, данные, признаки, обучение, метрики, ограничения и рекомендации. |
| [BPMN: жизненный цикл](bpmn/README.md) | Описание workflow жизненного цикла ML-модели и процесса согласования. |
| [BPMN-схема](bpmn/model_lifecycle.png) | Графическая схема процесса. |
| [Главный README](../README.md) | Установка, запуск, структура и ссылки на документацию. |

## Как всё связано

`README.md` → `docs/README.md` → `Model Card` и `BPMN`.

`Model Card` ↔ `BPMN`: в Model Card есть ссылка на BPMN, а BPMN-документация содержит ссылку обратно на Model Card.

BPMN описывает процесс, а Model Card — конкретную модель `Churn Random Forest` и правила её использования.
