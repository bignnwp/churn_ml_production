# Model Card: Customer Churn Prediction

## 1. Общая информация

**Название модели:** Churn Random Forest  
**Версия:** 0.1.0  
**Тип модели:** Random Forest Classifier  
**Задача:** бинарная классификация  
**Целевая переменная:** `Exited`

Модель предназначена для прогнозирования вероятности ухода клиента банка.

Модель реализована в production-ориентированном Python-проекте
`churn_ml_production`.

---

## 2. Назначение модели

### Основная задача

Модель прогнозирует, уйдет ли клиент из банка.

Целевая переменная:

- `Exited = 0` — клиент не ушел;
- `Exited = 1` — клиент ушел.

Результат модели может использоваться для:

- выявления клиентов с повышенным риском оттока;
- формирования списков клиентов для дальнейшего анализа;
- поддержки мероприятий по удержанию клиентов;
- анализа факторов, связанных с оттоком.

### Предполагаемый пользователь

Модель предназначена для использования специалистами по:

- аналитике;
- CRM;
- работе с клиентами;
- удержанию клиентов;
- управлению продуктами банка.

Модель не должна использоваться как единственный источник
для принятия решений относительно конкретного клиента.
